# Sample content

* `scripts/*.sura` — ready to use SuraScript behaviours. In the editor open **Assets ▸ + Script**,
  paste the file content into the script editor and attach it to an object (Inspector ▸ Add + ▸ Script).
* `scenes/` — exported scene files you can drop into a project's `Scenes/` folder.

The engine also ships five built-in demos: **File ▸ Load demo** →
platformer, shooter, pong, topdown, particles.
